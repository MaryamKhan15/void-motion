# VØID — Cinematic GSAP Experience

A futuristic, cinematic landing page built to showcase advanced web animations and interactive motion using GSAP.

The project focuses on immersive scrolling, typography animations, parallax effects, 3D transformations, and smooth visual transitions.

## ✨ Features

- 🎬 Cinematic page loader
- 🔤 Character-by-character text reveals
- 🌀 Advanced GSAP ScrollTrigger animations
- 🌌 Animated digital universe section
- 🪐 Floating planets and orbital animations
- 🔮 Clip-path portal image reveal
- 🧊 CSS 3D rotating cube
- 🎢 Scroll velocity based skew effects
- 🖱️ Custom animated cursor
- 🧲 Magnetic buttons
- ✨ Parallax and floating elements
- 📊 Scroll progress indicator
- 📱 Fully responsive design
- ⚡ Desktop and mobile-specific animations

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger

No frameworks were used.

cd void-motion

Then open index.html in your browser.

For the best development experience, use VS Code with Live Server.

📱 **Responsive Design**

The website is optimized for:

Desktop
Laptop
Tablet
Mobile

GSAP matchMedia() is used to provide different animation behavior for desktop and mobile devices.

Heavy desktop interactions such as the custom cursor are disabled on touch devices to keep the experience smooth.
